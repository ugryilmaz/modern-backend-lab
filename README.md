# Modern Backend Lab

Modern backend ve full-stack geliştirme pratikleri için oluşturduğum kişisel proje.

## Kullanılan Teknolojiler

- Node.js
- TypeScript
- Fastify
- Drizzle ORM
- PostgreSQL
- Zod
- React
- Next.js
- Docker
- Redis
- RabbitMQ

Proje ilerledikçe yeni mimari ve teknolojiler eklenecektir.
